Gồm:
- index.html (đã tối ưu giao diện không tràn màn hình)
- manifest.webmanifest
- sw.js
- README_VI.txt
- icon-192.png (giữ nguyên icon cũ của bạn)
- icon-512.png (giữ nguyên icon cũ của bạn)

Hướng dẫn cập nhật:
1. Giải nén file ZIP này.
2. Tải toàn bộ các tệp lên thư mục gốc của trang web/GitHub Pages của bạn (ghi đè file cũ).
3. Tải lại trang web trên điện thoại để trải nghiệm giao diện đã tối ưu.
